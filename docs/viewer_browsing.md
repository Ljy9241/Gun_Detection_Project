# 数据网页浏览与导出

## 使用方式

- 默认每页 **100条**，可选择25、50、100、200条，点击“查询”应用。
- 可以按设备、记录类型、采集日期、起止时间组合筛选。时间均为北京时间，按设备生成时间（包括推算时间）筛选，起止边界均包含。
- 设置起止时间后，尚无时间基准的记录不参与时间范围结果；不设时间范围可以查看这些记录。
- 页面底部提供首页、上一页、下一页、末页及输入页码跳转。翻页、跳转保留筛选和每页条数；修改筛选后查询回到第一页。
- 勾选“每10秒自动刷新”后，在第一页持续刷新。取消勾选立即停止；编辑筛选会暂停，点击查询后按勾选状态恢复。跳到其他页会停止自动刷新，避免打断历史浏览。页面在后台时不自动跳转。
- “查看最新”会按当前筛选重新查看最新记录；普通翻页保留接收时间快照，减少新上传记录造成的页间位移。
- CSV 导出当前筛选条件下的全部页，与当前页的接收时间快照一致，不受每页条数限制。导出采用逐行输出，不一次性将全部结果装入内存。
- CSV 使用 UTF-8 BOM，包含生成时间、时间来源、原始时间、角度、声音、坐标、事件编号及记录标识。用 Excel 导入时，生成序号、上电标识等标识列应指定为文本，避免长整数被自动转换丢失精度。
- 查询与导出均限定登录单位，并排除已隐藏的 pilot-001。CSV 中可能作为公式执行的文本会加前导单引号；数字角度仍保持数字。

## 更新现有云端

本次功能只需要更新 `cloud_backend/viewer.py`，不需要重新烧录设备或更改数据库结构。

将本地最新文件上传为服务器 `/tmp/viewer.py`，确认上传成功且实际网页工作目录为 `/opt/gun-viewer` 后执行：

```bash
sudo bash <<'BASH'
set -e
python3 -c "import ast; ast.parse(open('/tmp/viewer.py', encoding='utf-8').read())"
cp -a /opt/gun-viewer/viewer.py "/opt/gun-viewer/viewer.py.bak.$(date +%Y%m%d-%H%M%S)"
install -m 0644 /tmp/viewer.py /opt/gun-viewer/viewer.py
systemctl restart gun-viewer
systemctl status gun-viewer --no-pager
BASH
```

重新登录网页后检查每页条数、范围筛选、跳页、刷新及 CSV 下载。若反向代理额外设置了 CSP，应允许本次响应生成的 nonce 脚本，否则自动刷新脚本会被阻止；其他表单及导出无需 JavaScript。

## 验证范围

后端测试覆盖默认100条与四档页大小、跨页参数保留、页码越界、范围边界、无效范围、CSV全部页与中文编码、单位隔离、登录保护、自动刷新第一页限制和公式文本防护。云端部署和浏览器现场验收需在更新后完成。
