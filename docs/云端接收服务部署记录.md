## 6. 日常操作

在已授权的 Workbench 服务器终端内查看状态：

```bash
systemctl status gun-receiver --no-pager
journalctl -u gun-receiver --since today --no-pager
curl --fail http://127.0.0.1:18000/healthz
```

登记单位/设备必须使用配置文件中的数据库，而不是应用源码默认位置。以下只列调用方式，不包含任何现有密码：

```bash
set -a
. /etc/gun-receiver.env
set +a
cd /opt/gun-receiver/current
runuser -u gun-receiver --preserve-environment -- .venv/bin/python -m cloud_backend.admin create-tenant --id unit-a --name '实际单位名称'
runuser -u gun-receiver --preserve-environment -- .venv/bin/python -m cloud_backend.admin register-device --tenant unit-a --id '实际设备唯一编号' --name '实际设备名称'
```

令牌只在创建时显示，单独安全保管，不写入 Git 或部署记录。运行库尚无业务数据；开始正式接收前还需验证数据库备份和恢复策略。
